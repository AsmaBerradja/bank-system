# 🏦 Bank System Project

> A full-stack web application designed for a banking management system, built to handle client accounts, financial transactions, loans, and administrative tasks securely.

---

## 🚀 About the Project
This project is a secure and responsive web-based banking application developed using **PHP, MySQL, HTML, CSS, and JavaScript**. It provides a seamless experience for clients to manage their funds, calculate loan deposits based on their monthly income, and submit required documents, while giving administrators full control over system management.

---

## 🛠️ Built With & Technologies
* **Frontend:** HTML5, CSS3, JavaScript, FontAwesome
* **Backend:** PHP (Object-Oriented / Procedural logic)
* **Database:** MySQL (managed via phpMyAdmin)
* **Server Environment:** XAMPP (Apache & MySQL)

---

## ✨ Key Features
* **Client Dashboard:** Real-time account balance tracking, account number details, and navigation.
* **Loan Management System:** 
  * Dynamic calculation of required deposits based on loan type (Housing 30%, Car 25%, Electronics 15%).
  * Strict monthly income validation (Minimum 40,000 DZD requirement with bilingual alerts).
  * Supporting document upload (PDF/Images) for loan applications.
* **Loan Status Tracking:** Clients can view their application history and status (Pending / Approved).
* **Security:** Session-based authentication and role restriction (Client / Admin separation).
